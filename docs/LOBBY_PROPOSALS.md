# 大厅候选界面

供用户选择方向，尚未应用到正式大厅。入口：`/lobby-preview.html`。

| 方案 | 配色 | 界面组织 |
| --- | --- | --- |
| A 白底珊瑚 | 中性灰白、石墨文字、少量珊瑚橙 | 横向分类，牌桌精选与两款备选并排，开放封面画廊 |
| B 冷灰电蓝 | 冷灰、白色内容区、电蓝选中态 | 桌面左侧分类、更紧凑的精选行与游戏列表；手机分类横向排列 |
| C 深色街机 | 石墨黑、灰白文字、少量青柠 | 下划线分类、更大的实景牌桌、较少的面板背景；手机保留沉浸牌桌 |

三版均复用八款现有游戏封面，没有生成新资产，没有编造在线人数。搜索、分类、玩法介绍弹窗、方案切换和 390px 宽度切换可操作；产品导航为构图示意。卡时豆 30,000 明确标记为示例，不读取或更改账户。实际游玩入口返回原有大厅。

地址参数：`?theme=a&size=desktop`、`?theme=b&size=mobile` 等，参数白名单限制为 a/b/c 与 desktop/mobile。选择只体现在 URL，不写入浏览器存档，不调用游戏 API。

正式 `web/index.html`、`web/app.js` 和 `web/styles.css` 未引入这些候选。用户已选择 A，正在精修右侧游戏入口：农场、麻将改为独立大封面，图片与文字上下排列，移除重复类别标签。1000px 以下将备选游戏放到主精选下方，390px 保持两列封面。

动效限于输入反馈：精细指针悬停轻抬 4px、封面放大 4.5%、入口箭头出现；键盘焦点显示箭头，触屏保留箭头并提供按压反馈。Reduced Motion 禁止位移和缩放，保留静态状态。没有自动循环动画，没有引入动效库。仅使用原有两张封面，不生成新图。

不因构建或规则测试通过而视为视觉验收通过。A 精修仍为独立预览，等待用户确认后再接入完整大厅；本轮未公开部署。
