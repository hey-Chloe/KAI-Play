# 卡时豆与 GPU 入口

## 本轮产品规则

- 卡时豆沿用原服务端游戏点数账本，原有账户余额、对局与流水不重置。旧文档中的“竞技分”是它的历史名称。
- 新创建的游客账户一次性获得 30,000 卡时豆，由平衡账本记录 welcome 流水。
- 每个账户每天可点击领取 3,000，无低余额门槛，不补发缺席日期。新用户礼包与每日礼包可在同一天领取，共 33,000。
- 领取日期按服务端北京时间（UTC+8）计算，每天 00:00 重置；金额和日期不接受客户端指定。同一账户重复、并发或刷新请求不重复发放。
- 右上角余额为可展开控件。包含真实余额、每日领取状态和 GPU 入口；缺少账户连接时显示未知余额和重连操作，不虚构 30,000 已到账。
- 斗地主余额不足时保留当前页面并打开领取/充值面板；不自动跳走、不替玩家付款。其他本地免费游戏没有新增扣费。
- 用户提供的 GPU 入口为 `https://kai-gpu.itankg64.chatgpt.site/?release=0.8.0`，存于 `web/index.html` 的 `kai-gpu-url` meta；仅接受无嵌入凭证的 HTTPS 地址，新标签页打开并隔离 opener。

## 实现与兼容性

复用 `/v1/sessions/guest`、`GET /v1/me` 和 `POST /v1/relief`。Profile 新增 `dailyReward`（金额、已领、日期、时区），旧移动客户端忽略新字段仍可读取余额；本轮移动界面同步新的领取规则。现有账本类型与存档版本不变。

界面保留现有大厅、游戏桌面与导航，不新增视觉资产；领取面板使用原生 details/summary，提供关闭按钮、Escape、原生链接与状态文字。桌面靠右展开，小屏按视口收窄。规则/接口测试不代替真实移动端视觉验收。

## 明确未接通的部分

GPU 链接是页面跳转，不是支付回调。卡时豆仍是游戏点数，不等于真实 GPU 卡时，不可提现、转让或兑换。目前没有充值价格、订单、付款成功验证或付款后加豆；从 GPU 页面返回不会自动增加余额。

礼包按游客账户限制，不是实名自然人限制。清除游客凭证或创建另一账户可以获得新账户礼包；不应将该实现当成真实有价资产的防刷系统。单机 JSON 账本不支持多实例并发写入。

现有 Sites 公开展示包对 `/api/*` 返回 `SHOWCASE_MODE`，没有连接本仓库 Node 账户服务。所以本地完整服务可领取，静态公开展示不能领取；不得用 localStorage 假余额掩盖该差异。公开上线礼包前须连接受保护的账户服务或另行迁移托管账本，并经发布确认。
